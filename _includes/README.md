# _includes

## 역할

레이아웃 안에서 반복해서 불러오는 HTML/Liquid 조각들을 보관합니다.

## 이 프로젝트에서 중요한 파일

- `documents-collection.html`: 컬렉션 목록 렌더러
- `page__meta.html`: 날짜/읽기 시간 메타 출력
- `sidebar.html`: 노트 사이드바 출력
- `masthead.html`: 상단 메뉴 출력
