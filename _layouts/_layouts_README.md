# _layouts

## 역할

페이지와 노트가 어떤 구조로 렌더링될지 정하는 레이아웃 템플릿 폴더입니다.

## 주요 레이아웃

- `home.html`: 메인 페이지
- `single.html`: 개별 노트/페이지
- `archive.html`: 목록형 페이지
