# _layouts

## 역할

페이지 종류별 최상위 HTML 구조를 정의합니다.

## 이 프로젝트에서 중요한 파일

- `default.html`: 공통 래퍼
- `home.html`: 현재 홈에서 대표 노트와 포스트 섹션을 구성
- `single.html`: 일반 페이지와 노트의 상세 레이아웃
- `collection.html`: `site.notes` 같은 컬렉션 인덱스 페이지 렌더링
