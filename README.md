# Kwon Kwan Woo Study Notes

GitHub Pages와 Jekyll 기반으로 운영하는 개인 공부 기록 사이트입니다.

## 목적

- 수업 노트와 PDF 자료를 한곳에 정리하기
- 학습 과정과 메모를 다시 찾아보기 쉽게 보관하기
- 시간이 지나도 어떤 내용을 공부했는지 흐름을 추적할 수 있게 하기

## 주요 구조

- `index.html`: 홈 페이지
- `_notes/`: 핵심 공부 기록 컬렉션
- `_pages/`: 소개 및 노트 인덱스 페이지
- `_data/`: 네비게이션 데이터
- `assets/`: CSS, JS, PDF 같은 정적 자산

## 참고

- `docs/`, `test/`는 Minimal Mistakes 원본에서 남은 참고용 폴더이며 현재 사이트 빌드에는 포함되지 않습니다.
- 로컬 문서화용 README와 `VAULT_MAP.md`는 Obsidian 그래프 뷰를 위한 내부 문서입니다.
