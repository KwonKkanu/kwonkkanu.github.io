# 코테준비

## 역할

이 폴더는 코딩 테스트 준비 노트를 모아두는 공간입니다.

## 사용 규칙

1. 새 노트는 이 폴더 안에 `.md` 파일로 추가합니다.
2. Jekyll 페이지로 생성되게 하려면 파일 맨 위에 빈 front matter를 넣습니다.
3. 그 아래 첫 줄은 `# 제목`으로 시작하면 화면 제목이 자연스럽게 보입니다.

예시:

```md
---
---

# two sum

문제 풀이 정리...
```
