# _notes

이 폴더는 사이트의 핵심 공부 기록 컬렉션입니다.

## 현재 규칙

- 루트의 이 `README.md`만 안내 문서로 남깁니다.
- 실제 공부 기록은 `_notes/코테준비/` 안에 `.md` 파일로 추가합니다.
- 파일을 넣으면 `/notes/` 페이지와 개별 노트 페이지에 자동으로 반영되도록 맞춰두었습니다.

## 가장 쉬운 사용법

1. `_notes/코테준비/` 안에 새 `.md` 파일을 만듭니다.
2. 파일 첫 줄에 제목을 `# 제목` 형태로 적습니다.
3. 그 아래부터 내용을 자유롭게 적습니다.

예시:

```md
# 투 포인터

투 포인터 기본 개념 정리
```

## 참고

- GitHub Pages는 `jekyll-optional-front-matter`와 `jekyll-titles-from-headings`를 기본 제공해서, 노트에 YAML front matter가 없어도 처리할 수 있습니다.
- 제목을 예쁘게 보이게 하려면 첫 줄의 `# 제목`을 넣는 방식을 추천합니다.
