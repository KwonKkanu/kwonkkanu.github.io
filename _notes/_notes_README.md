# _notes

## 역할

이 폴더는 사이트의 핵심 공부 기록을 담는 Jekyll collection입니다.

## 현재 규칙

- 루트에는 이 `_notes_README.md`만 안내 문서로 둡니다.
- 실제 공부 노트는 하위 폴더 안에 `.md` 파일로 추가합니다.
- 새 노트를 페이지로 만들려면 파일 맨 위에 빈 front matter를 넣습니다.

## 빠른 사용법

1. `_notes/코테준비` 안에 새 `.md` 파일을 만듭니다.
2. 파일 맨 위에 아래 두 줄을 먼저 넣습니다.
3. 그 다음 첫 줄 제목을 `# 제목`으로 적습니다.

```md
---
---

# 문제 이름

풀이 정리...
```
